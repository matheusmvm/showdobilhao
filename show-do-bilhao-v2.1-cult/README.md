# Show do Bilhão — v2.2 Desafio Cult

Versão para GitHub Pages.

## Preset mantido
- 30 perguntas por partida
- 10 básicas + 10 médias + 10 avançadas nos 8 temas clássicos
- 45 perguntas disponíveis por tema clássico
- 10 perguntas: R$ 10.000
- 20 perguntas: R$ 100.000
- 30 perguntas: R$ 1.000.000
- 3 vidas / 3 erros
- 50:50, Plateia e Pular
- ranking local via localStorage
- interface responsiva
- avatares pixel art e background espacial

## Desafio Cult
- 9º painel na tela principal de categorias
- 50 perguntas CULT no banco
- 30 perguntas sorteadas por partida
- 60 segundos por pergunta, independente do cronômetro comum
- perguntas difíceis de cinema, arte, história, literatura, política, filosofia, nutrição, ciência e cultura geral
- mesmas ajudas, vidas e escada de premiação
- identidade visual própria em dourado/roxo/azul

## Publicação
Envie o conteúdo desta pasta para o repositório do GitHub Pages. O `index.html` já contém o JavaScript da aplicação; a pasta `assets/` contém os recursos visuais.
