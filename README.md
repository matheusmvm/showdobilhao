# Show do Bilhão — Demo 1.0

Quiz em pixel art, pronto para GitHub Pages.

- Username
- Escolha de tratamento: Homem / Mulher / Neutro
- Avatares pixel art
- 30 perguntas (10 básicas, 10 médias, 10 avançadas)
- Reações bem-humoradas
- Pontuação, sequência e ranking local
- Responsivo para notebook, tablet e celular
- Sem backend nesta demo

Publique `index.html` na raiz do GitHub Pages com `style.css`, `script.js` e a pasta `assets/`.
