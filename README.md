# Show do Bilhão — Demo 1.2

Versão visual/interativa baseada na Demo 1.1.

## Novidades
- Identidade visual azul-clara, creme e dourado, com background uniforme e menos poluído.
- Planta carnívora em pixel art integrada ao palco.
- Sacolas HC integradas como elemento colecionável/recompensa.
- Pack de visuais cosplay preservado em `assets/cosplay-pack.png` para expansão futura.
- GIFs leves de idle para planta, sacolas e avatares.
- Microanimações em CSS para reações e movimento de palco.
- Layout responsivo para notebook, iPad/tablet, iPhone e Android.
- Mantidos os 30 desafios, gênero/tratamento, avatar, ranking local e linhas de ajuda da versão anterior.
